Why naming it changes it

Discipline attacks the doing

Every one of the sixteen runs on the same loop. And the loop is why willpower keeps failing you, because willpower goes after the last link while the first one quietly manufactures more of the same.

Trace it backwards from the moment and you land on a belief nobody ever questioned. That is the only place any of this actually changes.

None of these are flaws. Every single one is protection that outlived the season it was built for.
